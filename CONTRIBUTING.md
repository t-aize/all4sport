# Contributions

Ce dépôt est un **projet pédagogique archivé** (BTS SIO, option SLAM — cas
d'étude fictif ALL4SPORT). Il est publié en lecture seule pour présenter le
travail réalisé.

**Aucune contribution n'est acceptée** : pas d'issues, de pull requests ni de
demandes d'évolution. Le projet n'aura pas de suite.

Pour l'installer et l'explorer en local, suivez le [README](README.md) et
[docs/commandes.md](docs/commandes.md).
